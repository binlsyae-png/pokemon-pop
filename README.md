# 포켓몬 팡팡! (PokeWhack!) ⚡🎮

포켓몬스터 캐릭터를 활용한 신나는 가로형 두더지잡기 웹게임입니다.
지우, 이슬이, 웅이, 세레나 중 마음에 드는 트레이너를 선택하고, 구멍에서 튀어나오는 포켓몬들을 전용 망치로 신나게 잡아보세요!

## 🌟 주요 특징

- **독립된 2단계 화면 구성**: 타이틀 및 트레이너 선택 화면과 실제 배틀 스타디움 게임 플레이 화면의 완벽한 분리
- **4인의 트레이너와 전용 망치 무기**:
  - 🧢 지우: 피코피코 뿅망치
  - 💧 이슬이: 아쿠아 스타 해머
  - 🪨 웅이: 바위 깨기 메이스
  - 🎀 세레나: 매지컬 리본 해머
- **두더지잡기 게임 플레이**:
  - 3×3 총 9개 구멍에서 포켓몬 랜덤 출현
  - 피카츄, 이브이, 이상해씨, 꼬부기, 파이리, 푸린, 고라파덕, 잠만보, 뮤 등 고유 점수 및 울음소리
  - 💣 **함정 폭탄(찌리리공/붐볼)**: 터지면 화면 진동 및 -5점 감점 & 콤보 리셋!
  - ⭐ **찬스 웨이브**: 포켓몬들이 대거 출현할 때 가장 높은 점수의 포켓몬을 잡으면 +10점 PERFECT 보너스!
- **풍성한 오디오 시스템**: Web Audio API로 구현된 9종 포켓몬 사운드, 망치 타격음, 카운트다운 비프, 칩튠 BGM
- **가로 화면 최적화 (16:9 비율)**

## 🚀 기술 스택

- HTML5 / CSS3 / Vanilla JavaScript (ES Modules)
- Web Audio API (합성 사운드 & 사운드 이펙트)
- 2D Canvas (파티클 시스템)
